# Prompt 06 — Revisión visual contra referencia

Compara la implementación final contra `docs/concientic_v5_reference.html` y contra el Manual de Marca/Sistema de Diseño.

Evalúa:
- jerarquía visual
- logo
- colores
- tipografía
- espaciado
- tarjetas
- metodología circular
- equipo de Guardianes
- responsive
- equilibrio entre blanco/oscuro
- ausencia de ruido visual

No copies literalmente el HTML. Corrige solo aquello que contradiga el sistema de diseño o reduzca claridad.

Prioriza consistencia de marca y experiencia consciente sobre efectos visuales.
