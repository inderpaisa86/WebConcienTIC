# Prompt 00 — Auditar antes de modificar

Actúa como arquitecto senior de Next.js y diseñador de sistemas web. Trabaja sobre el repositorio que actualmente despliega `https://concientic.vercel.app/`.

Antes de escribir código:
1. Inspecciona package.json, estructura, app/pages, componentes, estilos, assets, configuración de Vercel y variables de entorno.
2. Identifica el framework y versión real actualmente instalada. No asumas que el proyecto ya usa Next.js.
3. Ejecuta el proyecto y revisa visualmente la página actual.
4. Identifica placeholders, deuda técnica y qué partes pueden conservarse.
5. Lee `AGENTS.md`, `.kiro/steering/*` y `kiro/specs/concientic-web-redesign.md`.
6. Revisa `docs/concientic_v5_reference.html` solo como referencia visual.
7. Genera un informe breve con: estado actual, arquitectura, riesgos, plan de migración y archivos que modificarás.

No hagas cambios todavía. Termina solicitando aprobación implícita mediante el plan, no mediante preguntas innecesarias.
