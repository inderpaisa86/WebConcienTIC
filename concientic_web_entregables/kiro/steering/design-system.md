# Sistema de Diseño ConcienTIC

- `--color-secondary: #6C63FF`

- `--color-future-cyan: #00B4D8`
- `--color-dark: #0D1B2A`

- `--color-yellow: #FFC857`
- `--color-pink: #FF6EB6`

- `--color-soft: #F5F7F9`
- `--color-muted: #64748B`
- `--color-text: #1E293B`

## Tipografía
Poppins para marca, títulos y expresiones de identidad. Inter para UI, navegación y texto de lectura.

## Componentes
Construir botones, cards, section headers, badges, navegación, footer, guardian cards y patrones de evidencia como componentes reutilizables.

## Movimiento
Usar movimiento funcional y sobrio. Respetar `prefers-reduced-motion`. No usar animación para provocar permanencia o urgencia.

## Accesibilidad
Contraste AA como mínimo, foco visible, navegación por teclado, textos alternativos y jerarquía semántica correcta.
