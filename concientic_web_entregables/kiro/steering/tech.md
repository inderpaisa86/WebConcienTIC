# Stack técnico

- Next.js con App Router.
- React + TypeScript.
- Deployment objetivo: Vercel.
- Usar el stack existente del repositorio cuando sea compatible; no migrar innecesariamente dependencias.
- `next/image` para assets raster.
- Metadata y Open Graph mediante APIs de Next.js.
- CSS basado en design tokens; Tailwind solo si ya forma parte del proyecto o si se demuestra que simplifica el mantenimiento.
- Formularios preparados para integración futura; no fingir envío exitoso si no existe backend.
- Mantener cero errores de TypeScript, lint y build.
