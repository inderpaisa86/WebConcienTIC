# Checklist Vercel

- [ ] Repositorio conectado a Vercel.
- [ ] Framework detectado como Next.js.
- [ ] Build local exitoso.
- [ ] Node version definida si el proyecto lo requiere.
- [ ] Variables de entorno configuradas en Preview/Production.
- [ ] `.env*` sensibles fuera de Git.
- [ ] Imágenes servidas desde `public/` o dominios configurados correctamente.
- [ ] Metadata y favicon configurados.
- [ ] Preview revisada antes de producción.
- [ ] Formulario probado sin fingir éxito si no hay backend.
- [ ] URL de producción revisada.
